# Формат строк агента

Агент отвечает строками JSON, один объект на строку (NDJSON). Три типа строк.

## `car` — машина целиком

```json
{"t":"car","title":"BMW 525i E34, 1992","color":"#6b1626","colorName":"бордовый металлик","summary":"одно предложение"}
```

`color` — hex `#rrggbb`; если цвет неизвестен, поле пропускается и кузов остаётся серым.

## `part` — одна деталь

```json
{"t":"part","id":"door_rr","state":"defect",
 "issues":[{"kind":"dent","sev":2,"zone":"center","note":"вмятина от парковки"}],
 "src":"text","quote":"дословная цитата","conf":0.9}
```

| Поле | Значения |
|---|---|
| `state` | `ok`, `defect`, `missing` |
| `issues[].kind` | `scratch`, `chip`, `dent`, `rust`, `crack`, `repaint`, `replaced`, `cloudy`, `skew`, `flat`, `other` |
| `issues[].sev` | 1 косметика, 2 заметно, 3 серьёзно |
| `issues[].zone` | `front`, `rear`, `top`, `bottom`, `center`, `arch`, `left`, `right` |
| `src` | `text`, `photo`, `infer`; запасной парсер ставит `local` |
| `conf` | 0..1; `ok` с `conf < 0.5` показывается как «со слов продавца» |

Обязательны только `t`, `id`, `state` и для дефекта `issues[].kind`. Остальное имеет значения по умолчанию:
`sev` 1, `zone` `center`, `src` `text`, `conf` 0.8. Промпт просит модель не писать поля со значениями
по умолчанию: каждая лишняя строка токенов на локальной модели стоит секунд.

Не больше 4 дефектов на деталь. Новая строка для того же `id` заменяет прежнюю.
Деталь, о которой строки нет, остаётся в статусе «нет данных».

## `q` — вопрос продавцу

```json
{"t":"q","text":"Варили ли пороги?","part":"sill_l"}
```

`part` необязателен. Вопрос с текстом, который уже есть в списке или в отвеченных, игнорируется.
В режиме ответа на вопрос модель присылает строку `car` только с `summary` и может добавить
уточняющие `q`. К вопросам агента страница добавляет типовые вопросы по E34 (`KB` в `app.js`)
для деталей без данных.

## id деталей

Кузов: `hood`, `roof`, `trunk`, `bumper_f`, `bumper_r`, `fender_fl`, `fender_fr`, `door_fl`, `door_fr`,
`door_rl`, `door_rr`, `quarter_rl`, `quarter_rr`, `sill_l`, `sill_r`, `grille`, `mirror_l`, `mirror_r`.

Стёкла: `windshield`, `rear_window`, `glass_fl`, `glass_fr`, `glass_rl`, `glass_rr`.

Свет: `headlight_l`, `headlight_r`, `taillight_l`, `taillight_r`.

Колёса: `wheel_fl`, `wheel_fr`, `wheel_rl`, `wheel_rr`.

Суффиксы: `f`/`r` — перед/зад, `l`/`r` — лево/право по ходу движения.

## Как что рисуется

| kind | Панель кузова | Стекло | Свет | Колесо |
|---|---|---|---|---|
| `scratch`, `chip` | линии и точки в текстуре | звёздочка | — | — |
| `rust` | пятна; при `sev` 3 — дыры | — | — | — |
| `dent` | тень + сдвиг вершин | — | — | — |
| `crack` | тёмная линия | ветвящаяся трещина | потемнение | — |
| `repaint`, `replaced` | сдвиг оттенка, матовость | — | — | — |
| `cloudy` | — | — | желтоватая линза | — |
| `skew` | — | — | — | наклон «домиком» |
| `flat` | — | — | — | колесо приседает |
| `other` | только в карточке | только в карточке | только в карточке | только в карточке |

`state: "missing"` у любой детали — красный каркас вместо детали.
