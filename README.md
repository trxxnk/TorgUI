# E34 по объявлению

Демо: текст объявления о продаже BMW E34 (например, с av.by) превращается в состояние
3D-модели кузова. Локальная модель в LM Studio читает объявление и по строке на деталь
сообщает, что с ней: ржавчина, вмятина, перекрас, трещина, отсутствие. Модель кузова
перерисовывается по мере того, как приходят строки.

Сейчас сделан только кузов (32 детали: панели, стёкла, свет, колёса). Внутренние агрегаты
и сравнение объявлений — в [docs/roadmap.md](docs/roadmap.md).

## Запуск

Нужны Python 3 и LM Studio с включённым локальным сервером (по умолчанию `http://localhost:1234`)
и загруженной чат-моделью.

```bash
python3 server.py
```

Открыть `http://localhost:8734`.

Настройки через переменные окружения:

| Переменная | По умолчанию | Что значит |
|---|---|---|
| `PORT` | `8734` | порт демо |
| `LMSTUDIO_URL` | `http://localhost:1234` | адрес сервера LM Studio |
| `LLM_MODEL` | `bonsai` | подстрока в id модели; если не найдена, берётся первая чат-модель |
| `LLM_REASONING` | `none` | `reasoning_effort` для модели; пустая строка — не передавать параметр |

Зависимостей нет. three.js r128 и шрифты грузятся с CDN, поэтому первому открытию нужен интернет.

## Как пользоваться

- Три кнопки сверху — выдуманные объявления, разобранные заранее. Они показывают, как должен
  выглядеть результат, и работают без модели.
- Новое объявление: кнопка «+ Новое», затем либо ссылка на av.by и «Загрузить» (текст, характеристики
  и превью фото подтянутся сами, разбор начнётся сразу), либо вставить текст и нажать «Разобрать объявление».
- «Спросить у продавца»: под каждым вопросом поле для ответа. Ответ уходит модели, она меняет
  названные детали, переписывает описание и при уклончивом ответе добавляет уточняющие вопросы.
  Отвеченные вопросы остаются в списке «Уже отвечено».
- «Как выглядит» рисует дефекты на кузове. «Карта данных» красит детали по тому, что о них
  известно; серая штриховка — в объявлении об этой детали ничего нет.
- Клик по детали открывает карточку: дефекты, цитата из объявления, источник, типовая болячка E34.
- «Уточнить» — дописать своё наблюдение в свободной форме; меняются только названные детали.
- Если LM Studio не отвечает или модель отвечает не в том формате, текст разбирается запасным
  поиском по ключевым словам. Он заметно грубее, и об этом пишется в строке статуса.

## Скорость

Bonsai 27b на этой машине выдаёт примерно одну строку (одну деталь) за 10 секунд, объявление
из 13 деталей заняло около 200 секунд. Детали появляются на модели по мере ответа, кнопка «Стоп»
оставляет то, что уже пришло. С включёнными рассуждениями (`LLM_REASONING=medium`) модель думала
больше двух минут до первой строки, поэтому по умолчанию они выключены.
